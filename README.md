# 古菜谱

从公有领域的中文食经里抽出的菜谱表。一条记录是一道有名字、有做法、有原料的菜。同一本书里名字和原文都相同的只留一条；同一道菜出现在两本书里，各算一条。

目前 **4923** 条。原料和做法都有字。只点了菜名的菜单、席面和诗里的食单没有收，染帛、洗衣、牙药和房中文也没有收。没有凑到 8000。再往上，就只剩茶书、稻种名录、本草气味和一句一条的野菜，那些不是菜，没有收。

## 字段

| 字段 | 说明 |
| --- | --- |
| 菜名 | 书中的菜名或制法名 |
| 原料 | 原文里写了分量的配料；没有分量时，取原文里出现的食材名。抽不出来的整条不收 |
| 做法 | 书里的制法。没有制法的不收 |
| 出处 | 书名 |
| 时代 | 该书的朝代，不按单道菜猜测 |
| 原文 | 保持底本用字 |

茶茗门、稻作品种、鱼的分类、丹方，没有收。辍耕录这一份底本里没有回回食品那张单子。

## 底本

- 代知阁本：上表食经的大部分，以及清异录、寿亲养老新书、酉阳杂俎、礼记、吕氏春秋、夜航船、明宫史、北户录、广东新语、荆楚岁时记。
- 识典古籍转录：调鼎集、宋氏养生部、宋氏尊生部、食宪鸿秘。
- 维基文库：筵款丰馐依样调鼎新录。

茶录、茶经一类茶书，服食丹方，种树畜养，没有收进来。清稗类钞只取饮食类里正文就以菜名起头、并且写了做法的条目。

## 文件

- `data/古菜谱.csv`
- `data/抽查.txt` 每书前几条，用来看切分有没有把半句话当成菜名
- `extract.py` 抽取脚本

调鼎集是按栏抄下的无标点文本，有的菜名仍会粘在上一道的做法后面。宋氏养生部、食宪鸿秘里也有少量以半句话开头的条目。抽查时以原文为准。
